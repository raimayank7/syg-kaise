How to add a privacy policy page

Writing the policy is half the job. It must also be on a public page that visitors and ad networks can reach. These steps work for the three most common site builders.

Blogger

  • Generate the policy here and press "Copy as HTML".
  • In Blogger, open Pages, press New page and name it Privacy Policy.
  • Switch from Compose view to HTML view and paste. Publish.
  • Open Layout and add a Link List or Page gadget to the footer with the page address.
  • In Settings, under Privacy, make sure the blog is public.

WordPress

  • Generate the policy and press "Copy as HTML".
  • In Pages choose Add New, title it Privacy Policy and switch the editor to Code editor or add a Custom HTML block.
  • Paste and publish.
  • Under Settings > Privacy choose the page as your privacy policy page.
  • Add it to the footer menu under Appearance > Menus or in the Site Editor.

Wix

  • In the Wix editor open the Pages menu and add a new blank page called Privacy Policy.
  • Add a text element, paste the plain text version and format the headings.
  • Add the page to the footer: select the footer, add text, and link it to the new page.
  • Publish the site.

Check it works

Open your site in a private window and use a different device. Click the footer link. The page must load without a login, and must show the full policy. Search engines and ad reviewers read it the same way.

Common questions

Should the page be in the main menu?

The footer is enough, provided it appears on every page.

Can I use one policy for several sites?

Only if they really behave the same and are run by the same owner. Change the name and address on each.
